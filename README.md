# 올영 직원 판매 도우미 · DA22 v5

## 이번 버전의 목적
세 가지 핵심 메뉴를 하나의 상품 DB 위에서 검증하는 프로토타입입니다.

1. 대체 상품 찾기 — 고객이 원하는 상품이 미취급/품절일 때 현재 재고가 있는 후보 우선
2. 스킨케어·클렌징 카운슬링 — 피부 고민/카테고리 기반, 검증된 50개 분석 데이터 사용
3. 메이크업 카운슬링 — 피부타입/퍼스널컬러/톤/카테고리 UI 선구현

## 데이터
- DA22 V3 IndexedDB 백업에서 4,782개 상품 master 복원
- 기존 MVP에서 검증된 50개 분석 데이터 병합
- current_stock은 백업 당시 재고 스냅샷이며 실시간 재고가 아님
- 상세 성분이 없는 상품의 성분/효능은 추정하지 않음
