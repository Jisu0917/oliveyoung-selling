# Olive Young DA22 Employee Helper v3

## 이번 버전에서 바로 바뀐 것
- 기존 v2의 ZXing 바코드 인식 로직 유지
- 3,518개 DA22 상품을 런타임 DB에 탑재
- 분석 완료 50개 MVP 데이터와 나머지 상품 마스터를 하나로 병합
- 상품 비교 메뉴 추가: 최대 5개
- 상품 상세 → 비교 추가
- 고객 상담 메뉴 추가: 피부 타입 + 고민 + 카테고리 복수 선택
- 다크서클 상담 시 '케어 + 메이크업 커버' 조합 안내
- 검색은 기존처럼 띄어쓰기 토큰 단위로 동작
- PWA 캐시 버전 v4로 갱신

## 데이터 수집
`DA22_full_collector.js`를 올리브영 사이트에서 실행하면 공식 매장재고 API에
`includeSoldOut:true`로 요청하여 품절/재고 0 상품도 포함한 전체 상품 목록을 다시 수집합니다.

상품 상세 URL은
`https://www.oliveyoung.co.kr/store/goods/getGoodsDetail.do?goodsNo=상품번호`
형식으로 생성됩니다.

## 다음 단계
1. 전체 상품/품절 포함 데이터 재수집
2. 상세페이지의 제품 설명/전성분/색상/사용법 등 원천 데이터 수집
3. 원천 데이터 → 구조화 JSON
4. AI 오프라인 분석 → 검수
5. `product_analysis`, `product_ingredients`, `makeup_shades` 등으로 DB 확장
6. 직원용 1~3초 카드와 상담/비교 규칙을 정교화

주의: 올리브영 상세 페이지에는 협력사가 상품 정보를 직접 등록한다는 안내가 표시됩니다.
공개/상업 배포 시에는 원문·이미지의 복제/재배포 권한과 서비스 약관을 별도로 확인하세요.
