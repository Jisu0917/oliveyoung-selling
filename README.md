# 올영 직원 판매 도우미 · DA22 v7

이번 버전 변경사항
- 상품 검색: 검색어의 모든 단어가 상품의 여러 필드에 포함되면 매칭. 예: `메디힐 패드` → 메디힐 + 패드가 들어간 상품 전체 검색.
- 화면 전환 시 항상 스크롤 상단으로 이동.
- 하단 4탭: 홈 / 대체상품 / 스킨케어 / 메이크업.
- 첨부된 키티 이미지 분위기를 참고한 핑크·라운드 UI와 심플한 라인 아이콘.
- `Mallang-Galmuri11-R.ttf`를 전역 폰트로 적용.
- 상품 상세와 대체상품 선택 화면에 `매장 실시간 재고 확인` 버튼 추가.
- 실시간 재고 API: `https://m.oliveyoung.co.kr/oystore/api/stock/product-stock-v3`, DA22, includeSoldOut=true.
- 실시간 조회가 CORS/서버 제한으로 실패하면 저장된 재고 스냅샷을 별도로 표시.

주의: 정적 PWA에서 올리브영 API의 CORS 정책이 허용되지 않는 환경에서는 브라우저에서 직접 실시간 조회가 차단될 수 있습니다. 이 경우 다음 단계에서 작은 프록시를 붙이는 방식으로 해결합니다.
